# 🎯 Sber Events Parser

Автоматический парсер мероприятий с сайта [developers.sber.ru/kak-v-sbere](https://developers.sber.ru/kak-v-sbere), который фильтрует хакатоны и митапы по персональным критериям и присылает уведомления на email.

**Зачем это нужно?** Как начинающий Data Scientist, я ищу возможности для нетворкинга, участия в хакатонах и демонстрации навыков. Этот бот решает проблему ручного мониторинга афиши: он сам находит релевантные события (AI/ML/DS, онлайн, хакатоны) и присылает красиво оформленное письмо только тогда, когда появляется что-то новое.

## ✨ Ключевые особенности

- **Обход защиты от парсинга**: вместо `Selenium`/`Playwright` используется извлечение готового JSON из `__NEXT_DATA__` (Next.js). Быстро, надёжно, без браузера.
- **Умный скоринг**: события оцениваются по системе весов (тип события, темы, формат, ключевые слова). Нерелевантные отсекаются.
- **Определение онлайн/офлайн**: парсинг строки места проведения и эвристики для определения формата.
- **Дедупликация**: хранение `slug` просмотренных событий в `seen_events.json` (письмо приходит только при наличии новых).
- **HTML-шаблонизатор писем**: аккуратные карточки с датой, тегами, местом и ссылкой на регистрацию.

## 🛠 Стек технологий

- **Python 3.10+**
- `requests` — HTTP-запросы
- `python-dotenv` — безопасное хранение SMTP-креденшелов
- `smtplib` + `email` — отправка писем
- Стандартная библиотека для парсинга JSON и работы с датами

## 🗺 Этапы разработки

Проект создавался итеративно, от разведки структуры сайта до полной автоматизации:

1. **Разведка (Recon)**
   - Анализ HTML-ответа сервера. Выяснилось, что сайт рендерится на Next.js и отдаёт все данные в теге `<script id="__NEXT_DATA__">`.
   - Отказ от тяжёлых браузерных движков в пользу парсинга сырого JSON.
2. **Анализ структуры данных**
   - Рекурсивный обход JSON для поиска объектов `EventPage`.
   - Выявление полей: `StartDate`, `Place`, `CardButton`, `EventBadges`.
3. **Проектирование парсера**
   - Написание `parser.py`: извлечение, очистка и нормализация данных (приведение дат к ISO, извлечение города из строки).
4. **Скоринг и фильтрация**
   - Создание `filtering.py`: система весов для оценки релевантности под профиль пользователя (хакатоны +5, AI/ML +3, офлайн в другом городе 0 и т.д.).
   - Отсечение прошедших событий.
5. **Состояние и дедупликация**
   - Модуль `storage.py`: хранение `slug` в JSON. Защита от повторных писем.
6. **Отправка уведомлений**
   - `mailer.py`: генерация HTML-письма и отправка через SMTP (Gmail, Mail.ru и др.).
7. **Автоматизация**
   - Настройка запуска через Планировщик задач Windows (`.bat` + Task Scheduler).

## 🚀 Как запустить локально

1. Клонируйте репозиторий и перейдите в папку проекта:
```
   git clone https://github.com/pixy-kler/sber-events-parser.git
   cd sber-events-parser
```
3. Установите зависимости:
 ```
   pip install -r requirements.txt
```
5. Создайте файл .env в корне проекта и добавьте ваши SMTP-настройки:
```
   SMTP_HOST=smtp.gmail.com
   SMTP_PORT=465
   SMTP_USER=your_email@gmail.com
   SMTP_PASS=your_app_password
```
7. Настройте параметры фильтрации в config.py (ваш город, email получателя, веса релевантности).
8. Запустите парсер:
   ```
   python main.py
   ```
   
📁 Структура проекта
```
├── main.py            # Точка входа
├── config.py          # Настройки пользователя и веса скоринга
├── parser.py          # Загрузка и парсинг __NEXT_DATA__
├── filtering.py       # Логика фильтрации и скоринга
├── storage.py         # Работа с seen_events.json
├── mailer.py          # Отправка HTML-писем
├── requirements.txt   # Зависимости
├── run.bat            # Скрипт для Планировщика задач
└── .env               # Секреты (не коммитится)
```
